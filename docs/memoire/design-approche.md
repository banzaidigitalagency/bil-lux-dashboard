Pour les iterations design sur le dashboard BIL, ne pas refaire la structure. Garder les sections telles quelles. Garder le violet BIL (#702F8A) en couleur principale. Le travail doit etre de l'artisanat : typo coherente, tabular-nums, hairlines, ombres legeres, couleurs de canal aux bons endroits, details micro qui evitent le look "template IA".

**Pourquoi :** Le dashboard est client-facing pour la banque privee BIL. Pas de refonte souhaitee, l'objectif est que "ca ne se voit pas que c'est fait par IA". Demande explicite : "je veux garder les sections tel quel, je veux juste ameliorer un peu le design qu'on ne se doute pas que ce soit fait par IA. Il faut garder le violet de la BIL".

**Comment l'appliquer :** Quand une amelioration design est demandee, privilegier : harmonisation de l'echelle typo, solid colors plutot que gradients, borders hairline, labels en smallcaps + tracking, numeros tabulaires, micro-details. Eviter : restructurer les sections, introduire de nouvelles palettes, retirer le violet, animations exuberantes. Travailler par phases (valider avant de passer a la suivante).
